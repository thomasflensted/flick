Flick

A small, fast launcher for macOS. Press ⌘Space and start typing.

01

Apps

Open any app by typing a few letters. The ones you use most rise to the top.

02

Quicklinks

Save websites and folders. Add a keyword and an argument, so gh react searches GitHub.

03

Google search

Search Google straight from the panel, with suggestions as you type.

04

Snippets

Type a keyword in any app and it expands into text you saved.

05

Clipboard history

Everything you copy, searchable. Pick an old entry and paste it again.

06

Emoji

Press ⌃⌘Space to search emoji and paste one into whatever you're writing.

07

AI chat

Press Tab to ask a question, or ask it to change Flick: “add a quicklink that searches GitHub with gh”. Use any model on OpenRouter with your own key and switch with ⌘M.

08

Currency

Type 100 usd to eur and get the answer in the results.

09

Translate

Translate text between languages without opening a browser.

10

Live servers

See which local servers are running on which ports, and stop one with ⌘⌫.

11

Keep Awake

Stop your Mac from sleeping, for now or for a set time.

12

Raycast import

Bring your quicklinks and snippets over from a Raycast export.

Install

Flick needs macOS 14 or later.

Download Flick

1. Move it to Applications

On the download page, click the .zip file under Assets. Double-click it once it's downloaded, then drag Flick into your Applications folder.

2. Free up ⌘Space

Open System Settings → Keyboard → Keyboard Shortcuts → Spotlight and untick “Show Spotlight search”. If you use Raycast or Alfred, quit it first.

3. Open Flick

macOS will say it can't check the app. Click Done, go to System Settings → Privacy & Security, scroll down and click Open Anyway.

4. Allow access

The first time you paste or use a snippet, macOS asks for Accessibility and Input Monitoring. Switch Flick on in both lists.
